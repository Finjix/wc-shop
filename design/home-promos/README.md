# 首页固定活动图片

插画、背景和花字使用内置 imagegen 生成；原始提示词见 `prompts.json`。
左侧为米金色圆形背景、左边一摞及右边两枚金币、顶部厚圆花字“邀请返现”；右侧为
蜜桃奶油波浪背景、淡紫点缀礼盒和底部手写花字“加客服拿好礼”。两张成品均不透明。
左侧金色粒子闪烁漂浮，金币表面有星芒和扫光；右侧五角星向左下滑动，花字按
“加→客→服→拿→好→礼”顺序循环呼吸放大，蝴蝶结和带子单独轻摆。
所有可见文字直接包含在 GIF 内，页面只提供图片和无障碍标签。

安装 FFmpeg 和 gifsicle 后运行 `node scripts/build-home-promos.cjs`。
也可通过 `FFMPEG`、`GIFSICLE` 指定工具路径；制作脚本使用云函数开发依赖中的 Sharp
裁剪透明花字留白、绘制粒子和在固定画布上生成动画图层，再由 FFmpeg 合成。
逐帧画布尺寸保持一致，避免动态缩放产生横线残影。
成品输出到 `miniprogram/assets/home/`：256×256，35 帧，14 fps 时间轴，2.5 秒无限循环，
128 色调色板，不使用抖色，gifsicle `--lossy=20/40/80/120/200 -O3 -Okeep-empty`，选择满足
左图 500 KB、右图 700 KB 预算的最低有损强度。原始生成图片保留原分辨率。
GIF 帧时长以 10 毫秒为单位，因此帧间使用 70/80 毫秒，完整循环平均 14 fps。

本目录位于小程序根目录之外，不参与小程序上传。

## 轮播下方番薯推字横条

`sweet-potato.png` 由内置 imagegen 生成，原始提示词保存在 `service-promise-prompt.txt`。
运行 `npm run build:service-promise`（同样支持 `FFMPEG`、`GIFSICLE` 环境变量），
将角色交替迈脚和轻微起伏与固定文案“极速发货”“品质保证”“售后无忧”合成为
`service-promise.gif`。每组文字后跟三只小番薯，整体从右向左走，越过边缘后连续循环。
文字使用系统 Microsoft YaHei 粗体，在三倍画布上绘制后缩小；原图和脚本不进发布包。
成品 375×16 像素，128 色，14 fps，168 帧、12 秒无限循环，奶油米色不透明背景，
无抖色，gifsicle `--colors 128 --lossy=20 -O3 -Okeep-empty`。GIF 帧间隔用 70/80ms
交替近似 14 fps。页面显示宽度 100vw、高度 16px，异步图片加载前保留相同区域。
后台不再设置这条文字，保存和读取时忽略旧版 `bannerText`。
