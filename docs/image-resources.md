# 图片资源管理

后台侧栏的“图片资源”只统计业务引用的云端图片；不遍历存储桶，不包含未使用文件、暂存文件、固定头像、打包资源和外部图片。下架商品、历史订单、购物车、SKU 和首页配置中的图片也会被收集。同一 `fileID` 在总数中只算一次，可以出现在多个分类，分类数量不能直接相加作为总数。

“刷新盘点”分批扫描业务数据、读取文件头和真实字节数，完成后一次切换列表与汇总。失败保留上次完成结果，刷新可以继续任务。异常引用仍列出，未知大小不作为零字节计入空间；列表标明统计时间。

## 单张压缩与替换

启用中的管理员可查看列表，只有 `superadmin` 和 `admin` 可执行替换。点击“压缩并替换”会直接下载原图，在浏览器 Worker 中以 WASM 无损编码为 WebP；短边超过 1080px 时等比缩小。无损是编码输入像素的无损，不是缩放前像素或元数据的完整保留。现有小尺寸 WebP 也会重新编码，处理结果即使变大仍替换，并显示空间增减。

资源处理不限制原文件 10MB，不套用评价和售后新上传的 3MB 限制。正常后台上传、评价和售后上传规则保持不变。GIF、动态 PNG/WebP 和其他不支持的格式可查看，但不能压缩；损坏图片处理失败时不会替换原图。

替换任务先上传新的 `.webp` 到原目录，建立旧、新文件映射，再分批重读并更新明确的图片字段，包括订单、购物车和评价中的快照。普通文本中的链接不修改。写入业务图片时在事务内解析旧 ID，临时链接接口也会把旧 ID 解析到新文件。所有引用经过更新和复查后才删除原图。任务步骤有持久化状态、租约和版本检查，重复请求不会重复替换。

离开页面后可在“未完成的替换任务”继续；浏览器下载或编码尚未完成时会重新处理原图，上传已登记的任务从引用更新继续。引用开始更新前可以取消任务，仅清理本任务未使用的输出。开始更新后只允许继续完成，避免中途删除已引用的新文件。删除旧图失败时显示“替换完成，旧图清理待重试”。

## 云端配置与部署前检查

此次代码交付不执行部署或云端文件变更。发布前在当前环境创建以下服务端集合，并禁止客户端直接读写：

- `resourceControl`：当前完整盘点、正在扫描的任务和图片写入事务屏障。
- `resourceJobs`：扫描任务、替换任务、步骤进度、错误和租约。
- `resourceInventory`：按盘点版本及文件 ID 去重的列表和元数据。
- `resourceAliases`：持久化的旧、新文件 ID 映射；不得手工清除仍可能被旧客户端请求使用的映射。

推荐索引（`_id` 沿用默认索引）：`resourceInventory` 的 `scanID + _id`、`scanID + groups + _id`，以及 `resourceJobs` 的 `kind + status`。名称包含搜索使用转义后的正则匹配；如云端提示需要复合索引，按其查询诊断为 `scanID/name/groups/_id` 对应组合补建，不能返回部分列表或部分统计冒充完整结果。

发布云函数前，在 `resourceControl` 创建 `_id: current` 的初始文档（例如 `{ fence: "initial" }`），让图片写入事务始终有可读取的屏障。引用扫描每次最多处理 15 条业务记录、40 个图片引用，单条大订单可以跨请求继续；文件信息读取每次最多 5 个文件。

云函数需可读取上述业务及服务集合，读取文件信息、签发临时 URL 和删除旧图片。浏览器沿用现有登录身份直接上传到原目录；存储规则应允许有权限的管理员在首页、商品、分类、评价、售后及其他被引用图片目录创建替换文件。无需在前端或仓库配置永久 SecretId/SecretKey。

在真实后台域名验证云存储临时 URL 的跨域 GET 下载、Content-Length、ETag、Range 请求和 WebP 展示；浏览器需要允许加载同源 Worker 与 WASM。服务端只通过 HEAD 和最多 64KB 的文件头读取版本及动画标记，不下载完整图片进行压缩。文件头范围不足以确定动画时，浏览器处理前继续验证完整文件，避免截取动画第一帧。云端版本无法确认时禁止替换。

本地 `/upload` 的 `x-resource-job` 上传分支先验证管理员身份和任务，再写入任务指定路径；普通上传仍按原有目录规则校验大小。测试文件应使用独立 `LOCAL_BACKEND_DATA_DIR`，避免替换开发者的业务图片。

## 验证记录

- 云函数回归覆盖去重、分类、分页、下架与订单快照、排除闲置文件、未知大小、扫描失败恢复、版本冲突、替换结果变大、旧引用写入映射、并发字段保留、删除重试和权限。
- 上传回归覆盖现有资源超过 10MB 的独立处理选项及小尺寸 WebP 重新编码，保留普通后台上传规则。
- 在隔离本地数据中使用实际 Edge 浏览器验证侧栏、统计、筛选、搜索、不支持的格式、1080px 缩放、透明背景、旧图删除、快照更新及离开页面后的继续任务。
- 真实 CloudBase 环境的列举、临时链接跨域下载、上传、引用更新和删除尚未执行；本地与模拟 SDK 的结果不代表云端权限和跨域配置已经通过。
